# Medical Pathway

Plataforma para ayudar a médicos y estudiantes de medicina hispanohablantes de Latinoamérica a construir una carrera médica internacional con confianza, información verificada y acompañamiento paso a paso — no solo comparando países.

Este repositorio está en fase de **investigación y diseño de producto/arquitectura**, antes de escribir código. Toda decisión relevante queda documentada para poder retomarse en futuras iteraciones.

## Estado actual

Estrategia validada por el founder: el producto no es un comparador de países, sino la plataforma más confiable para acompañar a un médico durante su carrera internacional, con España como beachhead (confirmado con matriz ponderada) y el "Radar de Espera" (tiempos reales agregados de la homologación) como núcleo del MVP. Ver `docs/09-recomendacion-final-6-meses.md` para la apuesta completa y `docs/00-project-charter.md` para el estado detallado. Aún no se ha iniciado el desarrollo técnico.
